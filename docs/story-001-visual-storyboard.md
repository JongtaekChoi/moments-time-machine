# CH. 01 시각 콘티 — 또 깜빡했어

> 목표 플레이 시간: 8~10분  
> 텍스트 비중: 장면당 2문장 이하  
> 기본 공간: 현관 / 도윤의 방 / 식탁  
> 조작: 탭, 드래그, 짧은 선택

## 장면 1. 현관 — 가방이 온 날

**그림:** 저녁 현관. 가방, 간식 봉지, 코르크판, 우산. 왼쪽은 제목과 짧은 안내를 위한 여백.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 가방을 탭해 지퍼를 조금 연다 |
| 발견 | 구겨진 알림장 모서리 |
| 선택 | 가방을 식탁 의자 / 방 / 현관 바구니 중 하나로 드래그 |
| 코믹 탐색 | 우산을 탭하면 물방울이 ‘오늘도 수고했어’처럼 튀어 오르는 짧은 상상 |
| 짧은 글 | “내일 미술 시간에 쓸 준비물이 가방 안에 있다.” |
| 남는 변화 | 가방의 위치가 다음 장면 배경에 반영됨 |

## 장면 2. 방 — 구겨진 알림장

**그림:** 책상, 가방, 침대, 연필꽂이. 알림장이 조금 보인다.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 알림장을 두 손가락/드래그로 펴 본다 |
| 발견 | 색종이·풀·자가 필요하다는 작은 그림 목록 |
| 선택 | 풀통을 찾아 본다 / 나중에 보자 |
| 코믹 탐색 | 양말을 탭하면 한 짝이 “나는 준비물이 아니야”라며 숨는다 |
| 짧은 글 | “색종이는 있는데, 풀통은 텅 비었다.” |
| 남는 변화 | 풀통을 어디에 둘지 선택 |

## 장면 3. 식탁 — 말할 틈

**그림:** 엄마는 식사를 준비하고, 도윤은 공책 앞에 앉아 있다. 빈 풀통, 가방, 알림장이 자연스럽게 보인다.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 빈 풀통을 들어 엄마 쪽 / 가방 속 / 식탁 모서리 중 한 곳에 놓는다 |
| 발견 | 엄마의 손이 잠시 멈추고, 시계가 늦은 시간을 가리킨다 |
| 선택 | 풀통을 들고 다가가기 / 알림장만 보여 주기 / 숨기기 |
| 코믹 탐색 | 식탁 밑을 탭하면 미래의 도윤이 ‘내일의 나는 바빠!’ 쪽지를 흔든다 |
| 짧은 글 | “말하고 싶은데, 지금일까?” |
| 남는 변화 | 엄마의 첫 대사와 밤 장면의 물건 위치가 달라짐 |

## 장면 4. 잠들기 전 — 불 끄기 전

**그림:** 어두워진 방. 침대 곁, 책상 위, 문가의 엄마.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 알림장 또는 풀통을 엄마에게 건네거나, 서랍에 넣는다 |
| 선택 | “지금 말할래” / “내일의 나에게 맡길래” |
| 코믹 탐색 | 이불을 탭하면 꿈속의 내일 도윤이 바쁜 걸음으로 나타난다 |
| 짧은 글 | “불이 꺼지기 전에 말할 수 있을까?” |
| 남는 변화 | 아침 수습의 출발점 |

## 장면 5. 아침 — 세 가지 수습

**그림:** 현관의 밝은 아침. 가방, 알림장, 색종이, 빈 풀통, 시계.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 세 행동 카드 중 두 장을 현관 자석판에 붙인다 |
| 카드 | 선생님께 빌리기 / 색종이만 챙기기 / 오늘 저녁 바구니 만들기 |
| 코믹 탐색 | 시계를 탭하면 바늘이 너무 빨리 달리는 상상 |
| 짧은 글 | “지금은 누가 잘못했는지보다, 무엇을 할 수 있을지가 먼저다.” |
| 남는 변화 | 고른 카드가 ‘우리 집의 흔적’이 됨 |

## 장면 6. 같은 식탁 — 엄마가 본 것

**그림:** 장면 3과 같은 식탁을 반대 구도·다른 조명으로 본다. 엄마 주변에 빨래, 국, 휴대폰, 미완성 체크표가 있다.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 미완성 체크표를 탭해 빈 칸을 본다 |
| 발견 | 엄마도 ‘챙겼어?’라고 묻기만 했음을 알 수 있다 |
| 코믹 탐색 | 빨래 바구니를 탭하면 양말들이 대화를 한다 |
| 짧은 글 | “엄마도 가방을 같이 열어 보지는 못했다.” |
| 남는 변화 | 엄마의 메모 한 줄 |

## 장면 7. 우리 집에 남은 것

**그림:** 현관 코르크판/냉장고/가방 옆 선반. 이번 화에서 얻은 카드와 메모가 놓인다.

| 구분 | 내용 |
| --- | --- |
| 필수 조작 | 오늘 남길 흔적 하나를 원하는 자리에 붙인다 |
| 보상 | 체크표 / 앞주머니 쪽지 / 색종이 카드 / 반쯤 채운 메모 |
| 선택 | 이 장면 다시 보기 / 다음 월요일 보기 |
| 짧은 글 | “다음에도 보일 작은 흔적이 생겼다.” |
| 연속성 | 다음 화 배경에 계속 남음 |

## 구현 우선순위

1. 장면 1: 배경 + 가방 열기 + 가방 드래그 + 우산 코믹 반응
2. 장면 2: 알림장 펴기 + 빈 풀통 발견
3. 장면 7: 코르크판에 흔적 붙이기
4. 장면 3~6을 순서대로 연결

> 이 순서로 만들면 아직 전체 대본을 구현하지 않아도, ‘그림을 보고 눌러서 무언가를 발견하고 남긴다’는 핵심 재미를 초기에 검증할 수 있다.
