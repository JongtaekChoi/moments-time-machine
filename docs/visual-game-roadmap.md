# 시각적 게임 전환 로드맵

> 상태: 진행 중  
> 목적: 텍스트를 읽고 선택하는 프로토타입에서, 그림을 탐색하고 만지며 이야기를 경험하는 게임으로 전환한다.

## 1. 전환의 이유

현재 데모는 선택 구조를 검증했지만, 플레이어가 긴 문장을 읽고 버튼을 고르는 비주얼노벨에 가깝다.

이 프로젝트의 다음 버전은 아이가 **그림 속에서 발견하고, 눌러 보고, 상상하고, 집에 흔적을 남기는 게임**이어야 한다.

## 2. 핵심 플레이 루프

1. 장면을 본다.
2. 가방·알림장·풀통·엄마의 멈춘 손처럼 눈에 띄는 물건을 탐색한다.
3. 누른 물건에서 짧은 애니메이션, 상상 장면, 인물의 반응을 발견한다.
4. 한두 개의 행동을 실제로 조작한다. (열기, 펴기, 들고 가기, 붙이기, 넣기)
5. 그날의 일이 끝나면 집 안에 작은 흔적이 남는다.
6. 같은 장면을 다시 보거나 다음 월요일로 간다.

`다시 보기`는 더 좋은 결말을 얻기 위한 시험이 아니다. 다른 발견과 다른 반응을 보기 위한 놀이다.

## 3. 즐거움의 네 축

| 축 | 플레이어가 하는 일 | 보상 |
| --- | --- | --- |
| 숨은 마음 찾기 | 장면 속 물건·표정·행동을 누른다 | 짧은 반응, 새로운 관찰 |
| 엉뚱한 상상 | 풀통·가방 같은 물건을 눌러 본다 | 2~5초짜리 코믹 상상 |
| 작은 손맛 | 지퍼 열기, 종이 펴기, 카드 붙이기 | 눈에 보이는 변화 |
| 우리 집의 흔적 | 선택 뒤 체크표·쪽지·낙서를 현관에 남긴다 | 다음 화 배경이 조금씩 바뀜 |

## 4. 화면 원칙

- 한 화면의 텍스트는 기본적으로 2문장 이하.
- 선택지는 긴 문장 버튼이 아니라 장면 속 오브젝트 또는 행동 아이콘으로 제시한다.
- 모든 핵심 정보는 그림으로 먼저 보이고, 글은 보조한다.
- 한 장면에는 최소 하나의 필수 상호작용과 하나의 선택적 코믹 상호작용이 있다.
- ‘정답’, 별점, 실패 화면, 잠금 엔딩은 사용하지 않는다.

## 5. CH. 01 제작 순서

1. **시각 콘티 확정** — 7개 장면, 각 장면의 필수·선택 상호작용 정의
2. **아트 가이드 확정** — 캐릭터 비율, 집 구조, 저녁 조명, UI 안전 영역
3. **기본 배경 3장 제작** — 현관 / 방 / 식탁
4. **변형 자산 제작** — 가방 위치, 알림장, 빈 풀통, 인물 표정, 아침 조명
5. **첫 장면 구현** — 현관 탐색 + 가방 이동 + 코믹 반응
6. **CH. 01 전체 구현** — 아침 수습과 현관 선반까지 연결
7. **아이 플레이테스트** — 읽는 시간보다 누르고 발견하는 시간이 충분한지 확인

## 6. 완료 기준

CH. 01을 처음 해 보는 아이가 설명 없이도:

- 무엇을 눌러 볼 수 있는지 알아차리고
- 최소 세 번 이상 스스로 탐색하며
- 빈 풀통을 발견하고
- 마지막에 현관에 남은 흔적을 자기 것처럼 느끼고
- ‘다른 것도 눌러 볼래’라고 말할 수 있으면 성공이다.
