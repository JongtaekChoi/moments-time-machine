# 마음의 타임머신

아이와 부모가 같은 갈등을 각자의 시점으로 경험하고, 다시 말해 볼 기회를 갖는 짧은 웹 감정 어드벤처입니다.

첫 챕터 **〈또 깜빡했어〉**는 준비물을 자주 잊는 초등 저학년 아이와 반복 확인에 지친 엄마의 저녁을 다룹니다. 누군가의 숨겨진 상처를 찾는 이야기가 아니라, 기억에만 맡긴 확인 방식을 함께 바꾸는 이야기입니다.

## 실행

정적 사이트입니다. `dist/index.html`을 브라우저로 열면 플레이할 수 있습니다.

## 다음 챕터를 추가하는 기준

- 한 편은 7~10분 안에 끝난다.
- 아이와 부모 모두 이유는 이해받되, 상처 주는 행동이 정당화되지는 않는다.
- 타임머신은 정답을 알려주지 않고, 상대의 시점을 본 뒤 다시 말할 기회를 준다.
- 엉뚱한 선택지는 코믹하게 꼬이지만 누구를 망신 주거나 벌주지 않는다.
